# FinReg 프로젝트 Wiki

프로젝트 문서를 읽은 에이전트가 만든 탐색용 요약이다. 법규 답변용 말뭉치와 구분하며, 법률상 의무·적용 시점을 여기서 확정하지 않는다. 출처 문서가 판단 기준이다.

| 개념 | 읽을 때의 질문 |
| --- | --- |
| [근거·버전·시점](concepts/evidence-and-time.md) | 원문 수집과 기준일에 적용 가능한 근거 확보는 어떻게 다른가? |
| [RAG와 Wiki의 역할](concepts/retrieval-and-wiki.md) | 오프라인 후보 검색에서 원문 검증을 어떻게 유지하며 무엇이 남았는가? |
| [검수·평가 데이터 경계](concepts/evaluation-boundary.md) | 초안·사람 검수·등록 전 점검·개발 평가·최종 평가를 어떻게 분리하는가? |

[운영 규칙](AGENTS.md) · [변경 로그](log.md) · [도입 판단과 명령](../docs/llm_wiki.md)

현재는 위 세 개의 개발 개념을 정리했다. 법규 Wiki 자동 생성·서비스 검색 연동·RAG 대비 품질 평가는 아직 수행하지 않았다.

[오프라인 검색 실험](../docs/wiki_retrieval.md)은 원문 BM25·Wiki 후보 결합과 개발 비교 명령을 제공한다. 실제 검수 자료가 준비되기 전까지는 가상 규정의 동작 검증 결과로 구분한다.
