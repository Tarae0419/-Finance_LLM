## [2026-09-23] ingest | 프로젝트 지식 Wiki 시작

프로젝트 문서에서 [근거·시점](concepts/evidence-and-time.md), [검색과 Wiki](concepts/retrieval-and-wiki.md), [검수·평가 경계](concepts/evaluation-boundary.md)를 정리하고 [목차](index.md)를 만들었다. 출처와 의존 관계는 manifest에 기록한다.

[도입 설계](../docs/llm_wiki.md)에 개발 Wiki 도입과 법규 검색의 후속 비교 조건을 구분했다. 실제 법규 검수·Wiki 검색 연동·품질 개선 평가는 미완료다. 자동 구조 검사는 사람의 검수 이력이 아니다.

## [2026-09-23] lint | 초기 구조 검사

등록한 출처 5개와 개념 페이지 3개의 해시·의존 관계·목차·파일 링크 검사에 통과했다. `ruff check`와 새 코드 포맷 검사를 통과했으며 전체 테스트는 27개 통과, DB 설정이 필요한 14개 건너뛰기다. 이 중 Wiki 테스트 15개는 출처 변경, 줄바꿈 차이, 허용하지 않은 입력, 경로 이탈, 누락된 출처·목차·페이지, 중복 등록, 리디렉션, CLI 실패 종료 코드를 확인한다.

Windows 샌드박스의 pytest 임시 폴더 권한 오류 후 프로젝트 내 새 임시 경로에서 실행 권한을 조정해 확인했다. 법규 의미·품질·응답 성능은 이 검사 범위에 포함하지 않는다.
