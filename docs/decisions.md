| D-01 | 초기 업무 | 은행 대출상품 설명 관련 금융소비자보호 법규 확인. 정의·위임·부칙·별표를 포함한다. | PRD 기본안으로 개발 착수 |
| D-02 | 포함 질문 | 관련 규정 탐색, 근거의 의무·예외 확인, 상품·당사자·거래일 추가 질문, 검증 범위 내 시점 확인 | 개별 법률 결론은 원문 확보 후 검수 |

| D-04 | 지원 기간 | 원문·조문별 적용 정보가 확인된 범위만 지원한다. 수집 전에는 지원 가능한 날짜를 확정하지 않는다. | S1-03·07에서 확인 |
| D-05 | 실행·예산 | 사용자가 로컬 PC 우선, 유료 자원 사용 안 함을 확정했다. 클라우드 자원을 만들지 않는다. | 확정 |
| D-06 | 장비 | RTX 3070 Ti, VRAM 8,192MiB, 드라이버 591.86, RAM 34,186,153,984 bytes를 로컬 조회했다. | 모델·문맥 길이·학습 배치는 실험 후 선택 |
| D-07 | Python | 프로젝트 안에 Python 3.12와 `.venv`를 구성한다. 시스템 Python 3.14 설치는 교체하지 않는다. | API·향후 학습 패키지의 공통 실행 환경 |
| D-08 | DB | PostgreSQL 17.11을 프로젝트 `.runtime/postgres`에 설치하고 로컬 55432 포트에서 실제 연결을 검증했다. 한글 경로 호환을 위해 임시 드라이브 별칭을 사용하며 시스템 서비스는 등록하지 않는다. | 통합 테스트·실제 API HTTP 200 확인 |
| D-09 | 법규 정답 검수 | 사용자가 초안 → 사람의 존재·의미·시점·완전성 대조 → 검수 로그 → 외부 검토 구분 → 최종 평가 봉인을 지정했다. 외부 검토자가 없으면 공식 FAQ/해석자료 교차 대조를 최소 기준으로 삼는다. | [검수 정책](review_policy.md)에 기록; 사람의 확인 전 자동 reviewed 금지 |
| D-10 | 일정 | 주 20시간·8주안은 아직 실투입 시간으로 확인되지 않았다. 작업 결과와 미완료 조건을 기준으로 진행한다. | 실투입 시간 확정 시 일정 조정 |
| D-11 | 브랜치 | 기능별 `feat/<기능명>`을 사용한다. 환경 구성은 `feat/project-setup`에서 진행한다. | 사용자 확정 |
| D-12 | 기반 모델 실행 후보 | Qwen3-4B-Instruct-2507의 고정 리비전, NF4 4비트/BF16으로 로컬 실행한다. 모델 패키지는 `model` 의존성 그룹으로 분리했다. | [실행·자원 측정](model_runtime.md); 법규 품질을 검증한 최종 모델 채택은 아님 |
| D-13 | 작은 학습 실험 | 가상 무작위 토큰, 256토큰/배치 1/3단계, q_proj·v_proj LoRA rank 8로 자원 가능성을 확인한다. 저장·새 기반 모델 재로딩을 검사한다. | 실제 법규 draft는 학습하지 않으며 실험 어댑터의 릴리스 적격성은 false |

원문·가중치·정규화 데이터·비밀값·실행 캐시는 기본 Git 제외 대상이다. 코드·잠금 파일·설정 예시·출처/데이터 manifest·검수 보고서를 버전 관리한다. 질문 원문 저장 기능은 기본 환경에 추가하지 않는다.

기술 확인 자료: [FastAPI lifespan](https://fastapi.tiangolo.com/advanced/events/), [uv 저장 위치](https://docs.astral.sh/uv/reference/storage/), [PostgreSQL Windows 배포](https://www.postgresql.org/download/windows/). 실제 사용 패키지는 `uv.lock`에 고정한다.
