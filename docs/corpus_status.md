합계는 문서 3종, 구조 단위 2,035개, PDF 11개다. 구조 단위는 조·항·호·목·연속 문단·부칙 묶음을 포함하므로 법률상 조문 개수나 독립적인 평가 근거 개수와 같지 않다. 부모 조문은 하위 문맥을 보존하므로 본문이 중복될 수 있다.

- 원문 파일은 `data/raw/<sha256>.html` 또는 `.pdf`에 바이트 그대로 저장했다. Git에서는 원문을 제외하고 [수집 manifest](../data/manifests/corpus-20260922T135852661978Z.json)에 출처·수집 시각·해시·파일 위치를 기록했다.
- 조문 원문 위치는 UTF-8로 디코딩한 원본 HTML 문자열의 Unicode codepoint 범위 `[start, end)`다. 정규화는 HTML 텍스트 추출과 공백 정리에 한정하며 부정·단서·수치·단위를 제거하지 않는다.
- 기본 법률의 조·항·호와 필요한 목을 분리했다. 부칙은 원문 전체 묶음을 보존한다. 부칙의 개별 적용 관계와 PDF 표·단위·조건 추출은 아직 검수하지 않았다.
- 링크에서 추출한 참조 후보 4,766건은 모두 미해결 상태다. 같은 링크가 부모·하위 구조에서 반복될 수 있다. 정의·위임 관계의 의미 판정이나 특정 버전 대상 연결을 완료한 수치가 아니다.
- 조문별 `valid_from`·`valid_to_exclusive`는 미확인 상태로 두었다. 문서 시행일을 조문 적용일로 복사하지 않았으며 `temporal_review_status = unreviewed`다.
- 후보 스냅샷은 `309b08b6-8a66-5c9a-b7eb-23a65cd783ea`다. 활성 스냅샷은 없고 지원 기간도 아직 선언하지 않는다.

## 남은 검수

1. 대출상품 설명 질문에 필요한 정의·위임·예외·부칙·별표를 사람이 대조한다.
2. 11개 PDF의 표 구조·단위·적용 조건을 확인하고 관련 참조를 연결한다.
3. 수집 범위 밖 참조 자료가 필요한 질문을 구분해 추가 확보하거나 보류한다.
4. [금융위원회 FAQ(2차)](https://www.fsc.go.kr/po0201101/75701) 등 공식 보조 자료를 확보하고 질문별 교차 대조 여부를 기록한다. 해당 FAQ는 2021년 게시 자료이므로 2026년 질문에 그대로 적용 가능하다고 간주하지 않는다.
5. 검증한 조문 목록과 기간을 명시한 뒤에만 스냅샷을 활성화한다.

DB 구조·수집 경로가 준비되었더라도 위 검수가 끝나기 전에는 법규 답변을 서비스하지 않는다.
